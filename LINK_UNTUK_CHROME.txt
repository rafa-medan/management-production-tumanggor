🚀 SHORTCUT KEYBOARD (TIPS)
================================================================================

Di Browser Chrome:
Ctrl+L = Aktifkan address bar (untuk paste link)
Ctrl+C = Copy
Ctrl+V = Paste
Ctrl+W = Tutup tab
Ctrl+Tab = Pindah antar tab
F5 = Refresh halaman
Ctrl+F5 = Hard refresh

Di File Manager:
Ctrl+C = Copy
Ctrl+V = Paste
Ctrl+A = Select semua
Alt+D = Aktifkan address bar (untuk paste path)
