⚙️ SETUP LOCAL SERVER (UNTUK DEVELOPMENT)
================================================================================

Jika ingin server lokal dulu sebelum publish:

OPSI A: PYTHON SERVER (Simple - Recommended)
──────────────────────────────────────────
1. Buka Command Prompt di folder website
2. Jalankan:

   python -m http.server 8000

3. Buka di browser:
   http://localhost:8000

OPSI B: NODE.JS SERVER
──────────────────────────────────────────
1. Install Node.js: https://nodejs.org
2. Buka Command Prompt di folder website
3. Jalankan:

   npx http-server -p 8000

4. Buka di browser:
   http://localhost:8000

OPSI C: LIVE SERVER (VS CODE EXTENSION)
──────────────────────────────────────────
1. Buka folder di VS Code
2. Install extension "Live Server"
3. Right-click file HTML → "Open with Live Server"
4. Otomatis buka di browser di http://localhost:PORT

================================================================================
🔧 TROUBLESHOOTING
================================================================================

Problem: GitHub Pages tidak update setelah upload file?
Solution: 
- Tunggu 1-5 menit untuk GitHub rebuild
- Buka incognito/private mode di browser (bypass cache)
- Klik refresh (Ctrl+Shift+R untuk hard refresh)

Problem: Hosting file tidak bisa diakses?
Solution:
- Pastikan file sudah ter-upload di public_html
- Check folder permission (harus 644 untuk file, 755 untuk folder)
- Contact hosting support

Problem: Domain belum bisa diakses?
Solution:
- Tunggu DNS propagate (24 jam)
- Check DNS setting di domain registrar
- Pastikan hosting nameserver sudah benar

Problem: Login tidak bekerja di hosting?
Solution:
- Pastikan app.js (backend) sudah terupload
- Check Google Apps Script deployment URL
- Verify CORS settings
